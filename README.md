# Overview
This project extracts the elected government officials, including name, position and where they are representing (province, city, etc). The notebook extracts data from a pdf file where the data was stored in formatted pages. Regex was used in some to extract the data, which includes the governor, vice-governor, mayor and vice-mayor positions.

The code is found in extract.ipynb. The final extracted data was cleaned and saved in a csv file in the `data/` folder
